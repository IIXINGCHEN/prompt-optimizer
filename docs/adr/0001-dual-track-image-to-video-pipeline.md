# 0001. Dual-Track Optimization Pipeline for Image-to-Video

To support both state-of-the-art vision models and powerful pure-text reasoning models (e.g. DeepSeek-R1, OpenAI o1) in the Image-to-Video workspace, we decided to adopt an adaptive dual-track optimization pipeline. When the selected optimization model natively supports multimodal input, the prompt optimizer streams directly in a single pass with raw image latents; when a text-only model is selected, the system automatically routes the first frame through the global `imageRecognitionModel` to extract structured Visual Grounding text first, then feeds this visual context into the pure-text model for video prompt expansion. This strikes a balance between low latency with zero visual fidelity loss for vision LLMs, and wide compatibility with cost-effective, high-reasoning text-only LLMs.
